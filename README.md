## 發佈到網路上（GitHub Pages）

1. 把這個資料夾整包推上 GitHub。
2. repo 的 **Settings → Pages → Source** 選 `Deploy from a branch`，分支選 `main`、資料夾選 `/ (root)`。
3. 幾分鐘後網址會是 `https://<帳號>.github.io/<repo 名>/`。

`.nojekyll` 是給 GitHub Pages 用的，讓它原樣提供檔案、不要跑 Jekyll 處理。

## 離線使用

每個單元都是**單一檔案**，把 `units/` 裡的任何一個 HTML 拷到隨身碟（頁面上的「回目錄」在單獨使用時不會有作用）、傳到平板，雙擊就能開。第一次開啟時字型會從網路載入；沒有網路時會退回系統字型，功能完全不受影響。

## 檔案結構

```
index.html          目錄頁（會列出所有單元，可搜尋、可依年級篩選）
units/*.html        各單元，一個檔案一個單元，彼此獨立
.nojekyll           GitHub Pages 用
```

## 更新

目錄頁是產生出來的，不要手改。加了新單元之後：

1. 在 `_原始碼/mkindex.py` 的 `UNITS` 補一列（slug、來源檔名、年級、章節、標題、正課或補充卷、領綱主題、主線、搜尋關鍵字）。
2. 跑 `python3 mkindex.py <放離線 HTML 的資料夾> <這個資料夾>`。

實驗台數量是程式自己數的（數 `class="lab"`，舊版寫法數 `class="station"`），不必手動維護。
