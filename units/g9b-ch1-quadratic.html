同一條，搬了家

二次函數　·　從 y ＝ ax² 出發，搬到頂點、再找最高與最低

所有二次函數的圖形，都是 y ＝ ax² 搬家、伸縮來的；頂點說了算，最高和最低都在頂點。

支點一　最簡單的一條

y ＝ ax²：頂點在原點，a 管開口和胖瘦

所有二次函數的圖形都叫拋物線。先從最簡單的 y ＝ ax² 開始：頂點在原點，對稱軸是 y 軸，差別只在 a。

1

拉動 a。灰色虛線是 y ＝ x²，橘色是 y ＝ ax²。看 a ＞ 0 和 a ＜ 0 差在哪裡、|a| 變大時曲線往哪裡跑。

a ＞ 0 開口向上，有最低點；a ＜ 0 開口向下，有最高點；|a| 越大，同一個 x 的 y 越大，曲線越瘦。y ＝ 4x² 在 x ＝ 1 就到 4，y ＝ x² 要走到 x ＝ 2 才到 4，所以「乘 4」也可以看成「橫向壓成一半」。a ＝ 0 時平方那一項消失，變成直線，不是二次函數。
支點二　搬家

上下搬加 k，左右搬把 x 換成 x − h

y ＝ a(x − h)² ＋ k 就是把 y ＝ ax² 往右搬 h、往上搬 k。一般式 ax² ＋ bx ＋ c 是搬完家以後、把括號打開的樣子，配方就是把它搬回原位。

3

a、b、c 各管什麼

一般式 y ＝ ax² ＋ bx ＋ c。每次只動一個，看圖形哪裡在變。打開「頂點軌跡」再拉 b，頂點不是亂跑的。

x ＝ 0 代進去得 y ＝ c，所以 c 是和 y 軸的交點，和 b 無關；b 和 a 一起決定對稱軸 x ＝ −b/2a。b 變動時頂點 (−b/2a, c − b²/4a) 沿著 y ＝ c − ax² 走，它是一條開口相反的拋物線。b 不是「斜率」，不要把它當成一次函數的一次項係數。

配方 y ＝ ax² ＋ bx ＋ c ＝ a(x − h)² ＋ k 之後，頂點是 (h, k)；把整條曲線往右搬 −h、往上搬 −k，頂點回到原點，就是 y ＝ ax²。頂點公式 (−b/2a, (4ac − b²)/4a) 是配方做完一次的收據，不是第三招。
支點三　頂點說了算

最高、最低都在頂點；限定範圍時，要比一比端點

a(x − h)² ≥ 0 或 ≤ 0，所以頂點就是最低點（a ＞ 0）或最高點（a ＜ 0）。範圍一限定，頂點可能在範圍外面，最大、最小就跑到端點。

5

選一個函數，拉動範圍的左右端點。看最大、最小出現在頂點還是端點，頂點在範圍外時又是誰。

最小值
做法只有兩步：先配方，找到頂點；再看頂點的 x 在不在範圍裡。在，頂點就是最大或最小，另一個要到離對稱軸較遠的端點去找；不在，範圍裡一路上升或一路下降，最大、最小都在端點。

往後延伸　拋物線遇到別的線

交點的個數，看頂點的高度

水平線 y ＝ k 和拋物線有幾個交點，看 k 比頂點高還是低；斜線和拋物線的交點，就是聯立方程式的解，判別式決定個數。

7

交點有幾個

選一種線，拉動它的位置。兩邊的式子相等的地方就是交點；判別式是 0 的那一刻，線剛好碰到拋物線。

交點
y ＝ k 和 y ＝ ax² ＋ bx ＋ c 相交，就是解 ax² ＋ bx ＋ (c − k) ＝ 0；它的判別式是 b² − 4a(c − k)，正是「頂點的高度」的反映：k 越過頂點的 y 坐標，判別式就由負轉正。斜線的情形要先聯立，再看判別式；D ＝ 0 時只有一個交點，線和拋物線相切。
統整

同一條，搬了家

a 管開口和胖瘦；h、k 管搬到哪裡；配方把搬了家的拋物線搬回原位，頂點現身；最大值、最小值就在頂點，限定範圍時要比較端點。
