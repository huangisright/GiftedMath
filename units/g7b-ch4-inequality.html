答案是一整段

一元一次不等式　·　從天平與比較大小到負號讓不等號轉向

方程式的答案是一個點，不等式的答案是一整段。解的動作和方程式一樣，會讓不等號轉向的只有一件事：乘或除以負數。

支點一　答案是一整段

代一個數成立，只找到其中一個解

讓不等式成立的數有無限多個，畫在數線上是一段。分界的數本身是解就畫實心 ●，不是解就畫空心 ○。

1

天平

左邊三顆一樣重的球加 20 公克，右邊 100 公克。拉動一顆球的重量，看天平往哪邊沉；試過的重量會記在下面的數線上。

綠點是「往右邊沉」的重量，灰點不是。點越試越多，綠色會連成一整段——3x ＋ 20 ＜ 100 的解是 0 ＜ x ＜ 80/3。
2

畫在數線上

先看電腦怎麼畫，再換你畫：選方向、選實心或空心，按「檢查」。

「−3 ＞ x」和「x ＜ −3」是同一件事。把 x 放在前面讀，箭頭就指向不等號尖端那一邊。
支點二　翻過去就轉向

乘以負數，整條數線繞著 0 翻過去

加一個數是整條數線平移，乘一個正數是伸縮，左右順序都不變；乘以負數是翻轉，左右對調，不等號就要轉向。乘以 0 則把整條數線壓成一個點。

3

兩邊做同一件事

從 a ＜ b 出發，兩邊同加或同乘一個數 k。上面是原來的位置，下面是做完之後的位置。

把 k 從正數慢慢拉到負數，看兩個點在 k ＝ 0 那一刻疊在一起，再交換位置。
4

解題步驟機

輸入 ax ＋ b ○ cx ＋ d，看它一步一步解，最後一步會標出要不要轉向。再挑一個數代回去檢查。

x ＋ x ＋
係數 a − c 是負數時，除過去要轉向；是 0 時，x 消失了，只剩一句永遠對或永遠錯的話。
支點三　先讀懂再算

解完之後，回到情境裡挑

至少、不超過、未滿先翻成符號；解出來的一整段裡，題數、本數、人數只能是整數。往哪個方向取整數，看解的方向，不是四捨五入。

5

進位還是捨去

兩個情境解出來的數差不多，答案卻一個往上、一個往下取。拉動條件，看分界線落在哪兩根長條之間。

解是「x ≥ 某數」就往大的方向找第一個整數；解是「x ≤ 某數」就往小的方向找。
6

夾在中間

兩個條件同時成立，就是兩段重疊的部分。也可以切到「距離」，看 |x − c| ＜ r 怎麼變成一段。

兩段沒有重疊就無解；「≥ r」的距離題是分開的兩段，寫不成一個夾在中間的式子。
7

把 n 夾出來

49/12 和 (49 ＋ n)/(12 ＋ n) 之間有幾個正整數？拉動 n，數一數。

分子分母加同一個正數，分數會往 1 靠近。夾在中間的只能是 4，所以要 3 ＜ (49 ＋ n)/(12 ＋ n) ＜ 4——n ＝ 1～6，和是 21。
統整

答案是一整段

不等式的解是所有讓它成立的數，畫在數線上是一段；解的步驟和方程式一樣，最後一步看係數，負數就轉向；應用問題解完要回到情境裡挑數，兩個條件同時成立就取重疊的部分。

回到天平：一顆球的重量是 0 ＜ x ＜ 80/3——一整段。
